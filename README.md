# Anshuj Sahni — Portfolio

The personal portfolio of Anshuj Sahni: an annual-report style site with two
personas — **By day** (enterprise & SaaS sales across four industries) and
**By night** (brands, websites, films).

Built with Astro + GSAP. Fully static: no server, no external dependencies
(fonts and scripts are self-hosted).

## Structure

- `index.html` — the built page
- `_astro/` — hashed bundle (JS, CSS, fonts)
- `media/` — case-study videos + webp posters
- `logos/` — partner logos
- `netlify.toml` — publish config + long-lived cache headers

## Deploy

Auto-deploys on push via Netlify (`anshuj-pm` → https://anshuj.pm).
